# Исправления замечаний

Этот архив содержит только изменённые и новые файлы для проекта jsphotoshop из jsphotoshop1.rar.

## Установка

1. Распакуйте архив. Откройте папку jsphotoshop внутри него.
2. Скопируйте её содержимое в корень своего проекта, где находится package.json, с заменой файлов. Не создавайте дополнительную вложенную папку jsphotoshop.
3. В терминале корня проекта выполните:

```sh
npm install
npm test
npm run build
```

Исходники изменены; старую папку dist перед публикацией нужно пересобрать. После сборки публикуйте dist обычным способом для этого проекта.

## Глубина цвета PNG

Глубина в боковой панели и строке состояния теперь обозначается в битах на пиксель исходного файла. Для RGB с 8 битами на компонент это 24, RGBA — 32, Gray — 8, Gray + Alpha — 16; RGB с 16 битами на компонент — 48, RGBA — 64.

Палитровый PNG хранит один индекс палитры на пиксель: его глубина составляет 1, 2, 4 или 8 бит, а не индексная глубина, умноженная на три. Панель каналов при этом работает с декодированными RGB либо RGBA. Прозрачность tRNS не добавляет отдельные компоненты к хранящемуся потоку пикселей и не увеличивает его глубину. Для палитры Alpha появляется при наличии прозрачных записей tRNS, а не у каждого палитрового PNG.

Расчёт следует структуре IHDR и tRNS из спецификации PNG: https://www.w3.org/TR/png-3/

Для JPEG также читается число компонентов SOF, чтобы серый JPEG имел один канал, а RGB — три. GB7 сохранён как 7 бит серого с отдельным обозначением маски.

## Каналы

Удалены четыре изображения-представления, не являвшиеся отдельными каналами. Панель показывает только каналы документа: Gray; Gray + Alpha; R, G, B; R, G, B, Alpha. Все миниатюры монохромные и сохраняют пропорции. У каждого канала явно отображается состояние.

Выключение Gray обнуляет все три компонента отображения серого пикселя. Независимое переключение RGB убирает соответствующие составляющие. Только Alpha показывает непрозрачную монохромную маску; выключенный Alpha показывает цвета непрозрачными. Все выключенные каналы дают чёрный холст.

Переключение создаёт новый массив для отображения, не изменяя исходный. После загрузки другого файла состояние сбрасывается. Каналы теперь учитываются также при предпросмотре уровней и фильтра.

## Уровни

У ползунков единая шкала 0–255. Чёрная точка ограничивается значением white − 1, белая — black + 1, включая ввод чисел, дробных и некорректных значений. Обработчики сразу возвращают в поле фактически принятую величину, даже когда внутреннее значение уже находится на границе и Vue не вызывает повторный рендер.

Средний ползунок теперь управляет положением маркера полутонов на той же шкале; он остаётся между чёрной и белой точками. Гамма ограничена диапазоном 0.1–9.9. Перечень каналов в окне соответствует модели файла. Переключение флажка предпросмотра сразу обновляет холст.

## Проверка

29 проверок прошли: модели и глубины PNG, tRNS, серый и цветной JPEG, доступность и переключение каналов, неизменность исходных данных, ограничение точек уровней и восстановление значения в поле. Все Vue-компоненты прошли проверку компиляции. Производственная сборка Vite успешно выполнена.
